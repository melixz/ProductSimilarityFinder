# **ProductSimilarityFinder** 

## **Описание проекта**

**ProductSimilarityFinder** — это утилита на Python, предназначенная для поиска 50 наиболее похожих товаров для каждого товара из входящего списка. Основной принцип работы заключается в векторизации данных с использованием **TF-IDF**, а затем нахождении ближайших соседей с помощью **cosine similarity** через `NearestNeighbors` из `scikit-learn`. 


## **Технологии**
- **Python 3.12+** — основной язык разработки.
- **Pandas** — работа с табличными данными (Excel, DataFrame).
- **Scikit-learn**:
  - `TfidfVectorizer` — векторизация текстовых данных.
  - `NearestNeighbors` — поиск ближайших товаров.
- **OpenPyXL** — сохранение данных в Excel.
- **UV** — быстрый пакетный менеджер Python.
- **Argparse** — обработка аргументов командной строки.

---

## **Текущий функционал проекта**
1. **Чтение входного Excel-файла**:
   - Атрибуты: `Артикул`, `Категория`, `Название`.
   - Объединение `Категория` и `Название`, приведение к нижнему регистру.
2. **Векторизация данных**:
   - Используется **TF-IDF** (с `max_features=50000` и `min_df=2`).
3. **Поиск похожих товаров**:
   - Применение **cosine similarity** через `NearestNeighbors`.
   - Поиск 51 ближайшего соседа, исключение самого себя, сохранение 50 наиболее похожих товаров.
4. **Сохранение результатов**:
   - Excel-файл с колонками: `Артикул`, `Связанный артикул`.
   - Разбиение данных на несколько листов, если превышен лимит в **1 048 576 строк**.

## **Запуск проекта**

### **1. Установка UV**
Рекомендуется использовать **UV** — быстрый пакетный менеджер для Python:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

### **2. Клонирование репозитория**
```bash
git clone https://github.com/yourusername/product-similarity-finder.git
cd product-similarity-finder
```

### **3. Создание и активация виртуального окружения**
```bash
uv venv
source .venv/bin/activate  # Для macOS/Linux
.venv\Scripts\activate  # Для Windows (PowerShell)
```

### **4. Установка зависимостей**
```bash
uv sync
```

### **5. Запуск скрипта**
```bash
python script/process_catalog.py --input "data/Каталог1.xlsx" --output "output/Обработанный_файл1.xlsx"
```

Для обработки второго файла:
```bash
python script/process_catalog.py --input "data/Каталог2.xlsx" --output "output/Обработанный_файл2.xlsx"
```

После выполнения в папке `output/` появятся файлы с рекомендациями.

## **Формат входных и выходных данных**

### **Входные данные**
- Excel-файл с колонками:
  - `Артикул` (уникальный идентификатор товара).
  - `Категория` (категория товара).
  - `Название` (название товара).

### **Выходные данные**
- Excel-файл, в котором каждому артикулу соответствует **50 связанных артикулов**.
- Если строк слишком много, данные автоматически разбиваются на несколько листов (`Sheet1`, `Sheet2`, ...).

Пример выходного файла:

| Артикул | Связанный артикул |
|---------|------------------|
| A1001   | B2021           |
| A1001   | C3050           |
| A1001   | D4005           |
| A1001   | ...             |
| A1001   | X9090           |
| A1002   | B2050           |
| ...     | ...             |
